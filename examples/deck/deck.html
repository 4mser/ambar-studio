The numbers

One engine, three outputs.

30

frames per second, each one a call to render(t)

0

timeline editors. The narration is the timeline.

1

command from HTML to a finished MP4, PDF or PNG

The pipeline

From a page to a file.

HTMLyour scene
→
render(t)pure function
→
Chromeframe by frame
→
ffmpegencode + mix
→
MP4done

ambar render runs every step: narration, mix, frames and encode. ambar studio shows any frame before that.

AMBAR
Principle
If a frame depends only on time, you can render any frame, in any order, as many times as you want.
— the one rule of AMBAR
